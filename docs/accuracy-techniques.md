# 정확성 향상 기법 정리

이 프로젝트(NSMC 한국어 감성 분석기)에서 모델 정확도를 높이기 위해 적용된 기법들을 정리한 문서입니다.

---

## 1. 데이터 품질 관리

### 결측값 및 빈 문자열 제거
- **위치**: `src/data_loader.py:39~40`
- **내용**: NaN과 빈 문자열 리뷰를 학습 전에 제거한다.
- **이유**: 내용 없는 데이터로 학습하면 노이즈가 생겨 오히려 성능이 떨어진다.

### 텍스트 클리닝
- **위치**: `src/preprocess.py:51~57`
- **내용**: HTML 태그, 특수문자를 제거하고 연속 공백을 하나로 정리한다.
- **이유**: 감성 판단과 무관한 기호에 모델이 혼동받지 않게 한다.

### Stratified 분할
- **위치**: `src/preprocess.py:127~131`
- **내용**: train/val 분할 시 긍정:부정 비율을 동일하게 유지한다.
- **이유**: 한쪽으로 치우친 val 세트로 평가하면 성능 수치가 왜곡된다.

---

## 2. 학습 안정화

### Gradient Clipping
- **위치**: `src/train.py:119`
- **내용**: 역전파 시 기울기 크기를 최대 1.0으로 제한한다 (`max_norm=1.0`).
- **이유**: 기울기가 폭발적으로 커지면 가중치가 한 번에 크게 변해 학습이 망가진다.

### Linear Warmup 스케줄러
- **위치**: `src/train.py:320~330`
- **내용**: 학습 초반에는 학습률을 낮게 시작해 점진적으로 높인 뒤, 이후 선형으로 감소시킨다.
- **이유**: 사전학습된 BERT 가중치를 처음부터 강하게 업데이트하면 손상된다. 워밍업으로 안전하게 적응시킨다.

### Weight Decay (L2 정규화)
- **위치**: `src/train.py:323` (`weight_decay=0.01`)
- **내용**: 가중치 크기에 비례한 패널티를 손실에 더해 특정 가중치가 과도하게 커지는 것을 억제한다.
- **이유**: 가중치가 지나치게 커지면 학습 데이터에만 맞춰지는 과적합이 생긴다.

### Early Stopping
- **위치**: `src/train.py:386~392` (`patience=1`)
- **내용**: val loss가 직전 epoch보다 나빠지는 순간 학습을 중단하고, 가장 좋았던 시점의 체크포인트를 보존한다.
- **이유**: epoch를 무한정 반복하면 학습 데이터를 외워버려 새로운 문장에서 성능이 떨어진다.

---

## 3. 모델 선택

### klue/roberta-base (한국어 전용 사전학습 모델)
- **위치**: `src/preprocess.py:23`, `src/train.py:45`
- **내용**: 일반 다국어 BERT 대신 한국어 텍스트로만 사전학습된 모델을 사용한다.
- **이유**: 한국어 형태소·어휘를 이미 알고 있어 파인튜닝 효율과 최종 성능이 모두 높다.

### TF-IDF에 char n-gram 추가 (베이스라인)
- **위치**: `src/baseline.py:88~96`
- **내용**: 단어 단위 TF-IDF와 문자 단위(2~4글자) TF-IDF를 병렬로 결합한다.
- **이유**: 단어 단위만 쓰면 한국어의 조사·어미 변화에 취약하다. 문자 n-gram이 이를 보완한다.

---

## 4. 재현성 보장

### 랜덤 시드 고정
- **위치**: `src/train.py:63~72` (seed=42)
- **내용**: `random`, `numpy`, `torch`, `PYTHONHASHSEED`를 모두 동일한 값으로 고정한다.
- **이유**: 실험 결과를 동일하게 재현할 수 있어야 하이퍼파라미터 비교나 디버깅이 의미 있다.
